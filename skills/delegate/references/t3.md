# Delegate in t3

A worker is a t3 task. Call `orchestrator_capabilities` once per thread to see which providers and models are live, then `delegate_task` with the target provider, model and settings in `target.options`. `isolation: "worktree"` gives the worker its own checkout.

Same provider, same model, finishing this turn: your own native subagent is cheaper. Anything else (another provider, a reasoning level, a worktree, background work) goes through `delegate_task`.

Follow the task's `next`; don't poll it. Stop a worker you no longer need with `task_cancel`. A review is always a new `delegate_task`, never a message to the thread that wrote the code.

If a provider or model isn't available, say so; don't quietly swap.
